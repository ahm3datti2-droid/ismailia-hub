# دليل خدمات الإسماعيلية | Ismailia Super App

منصة دليل خدمات ومواصلات وطوارئ محافظة الإسماعيلية ومراكزها بتصميم Mobile-First وPWA.

## هيكل الملفات
- `index.html`: الواجهة الرئيسية والهيدر وشريط التنقل السفلي.
- `admin.html`: لوحة تحكم الإدارة (تسجيل دخول عبر Firebase Auth، إحصائيات، إضافة وتعديل وحذف الخدمات).
- `manifest.json` & `sw.js`: إعدادات تطبيق الويب التقدمي (PWA) والعمل أوفلاين.
- `css/style.css`: التنسيقات المخصصة وتأثير الزجاج الضبابي (Glassmorphism).
- `js/config.js`: إعدادات Firebase، بريد الأدمن الوحيد، التصنيفات، الأحياء والمراكز، وتعريفة المواصلات.
- `js/firebase.js`: تهيئة Firebase (App + Auth + Firestore) والتحقق من بريد الأدمن.
- `js/database.js`: طبقة إدارة البيانات في Firestore (مجموعة `services`)، مع بديل محلي بالخدمات الافتراضية عند تعذر الاتصال.
- `js/ui.js`: رسم البطاقات وحاسبة حالة العمل (مفتوح/مغلق الآن).
- `js/app.js`: المحرك الرئيسي للبحث الفوري، الفلترة، والنوافذ المنزلقة.
- `js/admin.js`: منطق لوحة التحكم (الدخول، الإحصائيات، البحث والفلترة، نموذج الخدمة، نشر الافتراضيات).

## Firebase والإدارة
- مشروع Firebase: `ismailia-hub` — Firestore في وضع الإنتاج، والقراءة للجميع والكتابة للمستخدمين المسجلين فقط.
- الدخول إلى لوحة التحكم عبر Firebase Authentication (Email/Password) فقط، والبريد الوحيد المسموح له بالإدارة محدد في `js/config.js` باسم `ADMIN_EMAIL`.
- لا يوجد أي رقم سري في الكود. لإنشاء حساب الأدمن: Firebase Console ← Authentication ← Users ← Add user، ثم تسجيل الدخول من `admin.html`.
- لنشر الخدمات الافتراضية الثلاث في Firestore: سجّل دخول الأدمن في لوحة التحكم ثم اضغط "نشر الخدمات الافتراضية" (يعمل فقط عندما تكون مجموعة `services` فارغة).
- طلبات الزوار من زر "أضف خدمتك" في الموقع العام تُحفظ محلياً فقط بانتظار مراجعة الإدارة، ولا تُنشر في Firestore إلا بعد موافقة الأدمن.

## طريقة التشغيل
افتح المجلد عبر **VS Code** باستخدام إضافة **Live Server** على ملف `index.html`، أو ارفع المجلد مباشرة على **Vercel** أو **Netlify**.
